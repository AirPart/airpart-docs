## Engineering Principles

- **Docs as Code:** Documentation lives in version control, evolves alongside implementation, and passes peer review in Pull Requests.
- **Zero Secrets Policy:** Never commit sensitive tokens, `.env` files, or production credentials to any repository.
- **Reproducible Environments:** Lock dependencies, enforce linter checks, and validate builds via continuous integration prior to merging.
